# Nguyên nhân lỗi không tải được danh mục thuốc mẫu trong mục "Tính liều thuốc"

## 1. Nguyên nhân (What's wrong?)

Trong trang **Tính liều thuốc** (`src/app/(dashboard)/dose-calculator/page.tsx`), component `<DoseCalculator />` đang được gọi mà không truyền prop `presets` chứa danh sách thuốc mẫu:

```tsx
// src/app/(dashboard)/dose-calculator/page.tsx (Dòng 24)
<div className="">
  <DoseCalculator />
</div>
```

Vì không nhận được prop `presets`, component `<DoseCalculator />` tại `src/components/features/dose-calculator/DoseCalculator.tsx` đã sử dụng giá trị mặc định là một mảng rỗng `[]`:

```tsx
// src/components/features/dose-calculator/DoseCalculator.tsx (Dòng 21-26)
export default function DoseCalculator({ 
  initialWeight, 
  initialTimesPerDay = 2,
  isEmbedded = false,
  presets = [] // Mặc định là mảng rỗng nếu không được truyền
}: DoseCalculatorProps) {
```

Do đó, thẻ `<select>` dùng để chọn thuốc mẫu chỉ hiển thị duy nhất lựa chọn mặc định `-- Tự nhập thông số --` ("Enter parameters manually") và không tải được dữ liệu thuốc đã lưu từ **Sample Drug Management** (Quản lý thuốc mẫu):

```tsx
// src/components/features/dose-calculator/DoseCalculator.tsx (Dòng 94-103)
<select ...>
  <option value="">-- Tự nhập thông số --</option>
  {presets.map((p) => (
    <option key={p.name} value={p.name}>{p.name}</option>
  ))}
</select>
```

---

## 2. Cách khắc phục (How to fix)

Vì `DoseCalculatorPage` là một Next.js Server Component, chúng ta có thể dễ dàng sửa lỗi này bằng cách lấy danh sách thuốc mẫu từ cơ sở dữ liệu thông qua action `getDrugPresets()` và truyền nó vào component `<DoseCalculator />`.

### Các bước sửa đổi file [page.tsx](file:///d:/skul9x/QLPK-SaaS-main/src/app/(dashboard)/dose-calculator/page.tsx):

1. Import `getDrugPresets` từ `@/actions/settings`.
2. Chuyển hàm component `DoseCalculatorPage` thành `async`.
3. Gọi `const presets = await getDrugPresets();`.
4. Truyền `presets` vào component `<DoseCalculator presets={presets} />`.

### Mã nguồn sau khi sửa đổi:

```tsx
import { Metadata } from 'next';
import { getAllSettings, getDrugPresets } from '@/actions/settings';
import PageHeader from '@/components/ui/PageHeader';
import DoseCalculator from '@/components/features/dose-calculator/DoseCalculator';
import DrugPresetManager from '@/components/features/dose-calculator/DrugPresetManager';

export async function generateMetadata(): Promise<Metadata> {
  const settings = await getAllSettings().catch(() => ({} as Record<string, string>));
  const clinicName = settings.clinic_name || 'Phòng khám';
  return {
    title: `Tính liều thuốc - ${clinicName}`,
  };
}

export default async function DoseCalculatorPage() {
  // Lấy danh sách thuốc mẫu từ database (Supabase)
  const presets = await getDrugPresets();

  return (
    <div className="flex flex-col gap-6">
      <PageHeader 
        title="Tính liều thuốc nhi khoa" 
        subtitle="Công cụ hỗ trợ tính liều siro/hỗn dịch cho trẻ em" 
      />
      
      <div className="">
        {/* Truyền danh sách thuốc mẫu vào đây */}
        <DoseCalculator presets={presets} />
      </div>
      
      <div className="">
        <DrugPresetManager />
      </div>
    </div>
  );
}
```
