# Plan: Patient Form Bottom Sheet UI
Created: 2026-05-02T07:09:56+07:00
Status: 🟡 In Progress

## Overview
Cải thiện trải nghiệm UX trên Mobile cho tính năng Thêm/Sửa Bệnh nhân (`PatientFormDialog`). 
Thay thế Modal căn giữa màn hình bằng giao diện **Bottom Sheet** (trượt từ dưới lên). 
Điều này giúp người dùng dễ thao tác bằng một tay, không bị che khuất khi bàn phím ảo hiện lên, và cho phép vuốt (swipe) để đóng nhanh.

## Tech Stack
- Frontend: Next.js 16, React 19, Tailwind CSS 4
- Animation: Framer Motion (có sẵn trong dự án)
