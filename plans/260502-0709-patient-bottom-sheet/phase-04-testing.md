# Phase 04: Testing & Refinement
Status: ⬜ Pending
Dependencies: phase-03-refactoring.md

## Objective
Kiểm thử và tối ưu hóa trải nghiệm trên các thiết bị di động thực tế/mô phỏng.

## Requirements
### Functional
- Bàn phím ảo không được che lấp ô input đang active.
- Thao tác vuốt xuống mượt mà, không xung đột với cuộn form.
- Nút "Lưu" luôn ở vị trí dễ bấm.

## Implementation Steps
1. [ ] Kiểm thử việc cuộn form khi focus vào input cuối cùng.
2. [ ] Kiểm thử cử chỉ kéo xuống để đóng form.
3. [ ] Kiểm tra responsive trên Desktop (giữ nguyên Modal như cũ).
4. [ ] Tinh chỉnh CSS nếu cần.

## Test Criteria
- [ ] Mở form trên Mobile -> Form trượt lên.
- [ ] Focus input -> Bàn phím hiện, form không bị lỗi layout.
- [ ] Kéo thanh ngang xuống -> Form đóng.
