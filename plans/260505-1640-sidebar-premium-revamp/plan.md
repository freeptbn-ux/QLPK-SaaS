# Plan: Sidebar Premium Revamp (Commercial Standard)
Created: 2026-05-05 16:40
Status: 🟡 In Progress

## Overview
Nâng cấp Sidebar hiện tại thành giao diện chuẩn "Premium SaaS" với các đặc điểm:
- Cấu trúc phân cấp rõ ràng (Navigation Grouping).
- Chế độ thu nhỏ (Collapsible Mini Sidebar) để tiết kiệm diện tích.
- Tích hợp thông tin người dùng (User Profile) và Quick Actions.
- Hiệu ứng thị giác cao cấp (Smooth animations, better active states, high-quality icons).

## Tech Stack
- **Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS + Vanilla CSS (for custom animations)
- **Icons**: Lucide React (Replacing react-icons/hi2 for a more consistent premium look)
- **Animations**: Framer Motion
- **Design System**: Accessible & Ethical (Cyan Healthcare Vibe)
