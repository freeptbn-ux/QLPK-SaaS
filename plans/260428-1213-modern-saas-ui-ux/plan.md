# Plan: Modern SaaS UI/UX System-wide Revamp
Created: 2026-04-28T12:13:03+07:00
Status: 🟡 In Progress

## Overview
Nâng cấp toàn bộ giao diện QLPK SaaS (Bệnh nhân, Kho thuốc, Thống kê, Cài đặt) theo phong cách Modern SaaS. Giữ nguyên màu xanh dương (Blue) chủ đạo.
Đặc trưng:
- Nền ngoài cùng màu xám nhạt (`bg-slate-50`).
- Các khối nội dung bo góc lớn (`rounded-xl` hoặc `rounded-2xl`) nền trắng.
- Đổ bóng cực mềm (soft shadows) tạo chiều sâu.
- Bảng dữ liệu có khoảng cách thoáng, các nút thao tác (Sửa/Xóa) được tái cấu trúc để tránh bấm nhầm (Error Prevention).
- Bổ sung Empty States đẹp mắt.

## Tech Stack
- Frontend: Next.js + Tailwind CSS
- Icons: Lucide React / Heroicons
